# Метрики

## Стек

- Язык: Go.
- TSDB: VictoriaMetrics Single.
- Формат метрик: OpenMetrics / Prometheus.
- Развёртывание VictoriaMetrics: Helm-чарт vm/victoria-metrics-single.

## Экспортёры

1. Встроенный HTTP-экспортёр приложения:
    - Реализован с помощью promhttp.Handler() на эндпоинте /metrics (порт 8080).
    - Экспортирует метрики Go runtime (память, процессор, горутины), сетевые метрики HTTP-запросов и кастомные бизнес-метрики.

2. Экспортёр PostgreSQL (postgres-exporter):
    - Готовый sidecar-контейнер prometheuscommunity/postgres-exporter:v0.20.1 в поде PostgreSQL (порт 9187).
    - Собирает показатели СУБД: число активных подключений, транзакции, блокировки, размер БД.

## Реализованные метрики

Бизнес-метрики:
1. users_registered_total (Counter) — общее число зарегистрированных пользователей.
2. auth_attempts_total (CounterVec, метка status: "success" | "failure") — количество успешных и ошибочных попыток авторизации.
3. items_created_total (Counter) — количество созданных записей в каталоге.
4. catalogio_entities_current (GaugeVec, метка type: "item" | "item_type" | "item_status") — текущее количество сущностей в БД (растет при создании, падает при удалении).

Технические метрики:
1. http_requests_total (CounterVec, лейблы method, path, status) — количество входящих HTTP-запросов.
2. http_requests_duration_seconds (HistogramVec) — гистограмма длительности обработки запросов.
3. go_*, process_* — стандартные метрики рантайма Go.
4. pg_stat_* — метрики базы данных PostgreSQL.
